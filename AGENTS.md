# Profile Repository Guidance

Before working on any task in this repository, read the following documents
to understand the project's domain rules and technical architecture:

- [BUSINESS.md](BUSINESS.md) — product behavior, operating modes, account
  identity rules, content model, and authentication/security policies.
- [ARCHITECTURE.md](ARCHITECTURE.md) — infrastructure, project structure,
  dependency rules, C# conventions, and testing requirements.

These documents together define the constraints that all code changes must
respect.
